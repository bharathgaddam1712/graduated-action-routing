# PAgE 2027 Overleaf Upload Notes

Upload this whole folder to Overleaf:

- `main.tex`
- `references.bib`
- `figures/`

Recommended compiler:

- `pdfLaTeX`

The draft uses the ACM/SIGPLAN `acmart` class:

```tex
\documentclass[sigplan,screen,review,anonymous,nonacm]{acmart}
```

This matches the PAgE 2027 CFP constraints as currently posted:

- anonymized review submission
- up to 8 pages, excluding bibliography
- standard SIGPLAN two-column format

Before final/camera-ready presentation, remove `review,anonymous` and restore
the author block.

The red margin numbers are review line numbers generated by `review`.
The PAgE CFP does not explicitly require line numbers or their color. Keep
them for convenient review, or remove only `review` for a clean anonymous
reading copy. Keep `anonymous` for the submission.

CFP checked on 2026-10-12: https://popl27.sigplan.org/home/page-2027
Accepted submissions are presented at the workshop, not published in the ACM
Digital Library.

The audited draft is `main.tex` in this folder. The older `../paper/main.tex`
is not synchronized. Upload the newly rebuilt ZIP when replacing an older
Overleaf project; local edits do not update an existing Overleaf project.

`AUDIT_NOTES.md` records substantive corrections and remaining limitations.
`audit_figures.py` regenerates plots using the repository's existing result
CSVs, pandas, matplotlib, and scikit-learn. It is not needed by LaTeX.
The figure images have no embedded figure numbers; LaTeX assigns numbering.
Compilation and the eight-page body limit still require PDF verification.
